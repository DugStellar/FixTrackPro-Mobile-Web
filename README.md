## 📌 Project Overview
FixTrack Pro is an integrated mobile and web solution engineered for Cape IT Assist to manage client repair workflows, event RSVPs, notifications, and automated raffle systems. 

This repository houses the source code for both the web microsite and the mobile application, integrated with an online database and managed using Azure DevOps lifecycle principles.
